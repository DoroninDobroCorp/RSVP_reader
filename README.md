# 📖 RSVP Speed Reader

Быстрая читалка по методу RSVP (Rapid Serial Visual Presentation) с поддержкой оффлайн-режима и мобильных устройств.

## 🎯 Основные возможности

### ✨ Функциональность
- **RSVP режим** - одно слово за раз для быстрого чтения
- **Фокусная буква** - выделение одной буквы другим цветом для лучшей фокусировки
- **Настраиваемые паузы** - отдельные множители для запятых, точек и других знаков препинания
- **Отслеживание прогресса** - процент прочитанного и закладка
- **Двойной клик** - для переключения между RSVP и обычным режимом чтения
- **Обычный режим чтения** - прокручиваемый текст с подсветкой текущего слова
- **📚 Поддержка EPUB** - загружайте файлы .epub напрямую, автоматическое извлечение текста

### 📱 Мобильность
- **PWA (Progressive Web App)** - установка на главный экран телефона
- **Офлайн работа** - работает без интернета после первой загрузки
- **localStorage** - сохранение текста, настроек и закладок локально
- **Адаптивный дизайн** - оптимизирован для мобильных устройств

### ⚙️ Настройки
- **Скорость чтения** (WPM - слов в минуту): 100-1000
- **Пауза на запятую**: множитель 1-5x
- **Пауза на точку**: множитель 1-5x  
- **Пауза на ; : ! ?**: множитель 1-5x
- **Цвет фокусной буквы**: любой цвет
- **Размер шрифта**: 30-120px

### 🎮 Управление

#### В RSVP режиме:
- **Пробел** - пауза/воспроизведение
- **← / →** - предыдущее/следующее слово
- **Escape** - выход в обычный режим
- **Двойной клик** - выход в обычный режим

#### В обычном режиме:
- **Клик на слово** - переход к этому слову
- **Двойной клик** - запуск RSVP режима
- **Кнопка ▶️** - запуск RSVP режима

## 🚀 Запуск

### Вариант 1: Простой HTTP сервер (Python)
```bash
cd /srv/RSVP_reader
python3 -m http.server 8080
```

Затем откройте: `http://localhost:8080`

### Вариант 2: Node.js сервер
```bash
npx http-server /srv/RSVP_reader -p 8080
```

### Вариант 3: PHP сервер
```bash
cd /srv/RSVP_reader
php -S localhost:8080
```

## 📲 Установка на телефон

1. Откройте приложение в браузере на телефоне
2. В Chrome/Safari нажмите "Добавить на главный экран"
3. Приложение будет доступно как обычное приложение
4. Работает полностью офлайн после установки

## 💾 Хранение данных

Все данные хранятся локально в браузере:
- **Текст** - автоматически сохраняется при вводе
- **Закладка** - сохраняет позицию чтения
- **Настройки** - сохраняются при изменении

## 🎨 Технологии

- **Vanilla JavaScript** - без зависимостей
- **CSS3** - современный адаптивный дизайн
- **Service Worker** - офлайн функциональность
- **localStorage** - локальное хранилище
- **Web App Manifest** - PWA возможности

## 📝 Использование

1. **Загрузка текста**:
   - Вставьте текст в текстовое поле
   - Или загрузите .txt файл
   - Или загрузите .epub файл (автоматически конвертируется в текст)

2. **Начало чтения**:
   - Нажмите "Начать чтение"
   - Двойной клик для запуска RSVP режима

3. **Настройка**:
   - Откройте настройки (⚙️)
   - Измените скорость, паузы, цвета
   - Настройки сохраняются автоматически

4. **Возврат к чтению**:
   - Приложение запомнит позицию
   - Продолжайте с того места, где остановились
