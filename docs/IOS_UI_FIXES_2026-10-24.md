# HummingRead 1.0 (2) — исправления и обновление iPhone

24 октября 2026. Исходники изменены на serverforvovka:/srv/hummingread; Mac использован только как разрешённый Xcode build/sign/test host. Установлена development-сборка 1.0 (2), bundle ID team.ibet.paceflow сохранён.

## Что исправлено

- На узком экране выбор шрифта перестраивается в два столбца; полные подписи EN/RU/ES помещаются в кнопках, touch targets остаются не меньше 44 px.
- Найдена дополнительная функциональная ошибка: обработчик кнопок вызывал отсутствующий setFontFamily. Теперь шрифт применяется и сохраняется, normal text получает выбранную гарнитуру, а в RSVP пересчитывается отображение слова после смены шрифта.
- Выбранные кнопки шрифта получают aria-pressed. Это исправление доступного состояния, а не заявление о полном VoiceOver QA.
- Удержание текста кнопок больше не вызывает выделение и системное меню копирования; выделение обычного текста книги не отключалось.
- Из локализованной сводки библиотеки убраны технические названия app storage / IndexedDB / localStorage; остаются книги, слова и понятное состояние хранения/синхронизации.
- iOS build повышен с 1 до 2. Поколение веб-ресурсов и offline cache повышено с v54 до v55.

## Проверки

- Новая проверка границ подписей воспроизвела прежний дефект до изменения CSS: Rounded выходил за кнопку даже в EN на 320 px. После исправления проверены EN/RU/ES на 320, 390 и 768 px в Chromium, WebKit и Mobile Safari emulation.
- Функциональная проверка переключает все четыре шрифта, проверяет применение Mono к книге и восстановление шрифта вместе с прежним словом после перезагрузки.
- Модульные проверки: 107 / 107 PASS. Проверки упаковки, iOS source, precache и built web paths: PASS. Offline: 7 / 7 PASS.
- Исходный полный browser run: 227 PASS, 1 FAIL из-за гонки самого теста с запланированной перезагрузкой после Delete All. Вместо фиксированного ожидания 700 ms тест ждёт main-frame navigation и DOMContentLoaded. Не изменяя логику удаления приложения, исправленный сценарий перепроверен во всех трёх браузерах: 3 / 3 PASS. Исходный неуспешный лог сохранён, результат не переименован в чистый полный прогон.

## Обновление физического iPhone без удаления данных

Владелец разблокировал подключённый телефон. Остановлен только процесс HummingRead. Через штатный devicectl скопированы Documents и Library в закрытую папку на личном Mac; данные книг не передавались в публичный репозиторий или на сайт.

Сохранено 28 файлов, 10 945 924 байта. Build 2 установлен поверх build 1 с тем же bundle ID. До первого запуска снова скопированы Documents/Library: ни один прежний файл не отсутствует и ни у одного не изменились размер или SHA-256. Отдельно проверены 13 файлов постоянного состояния Documents / Preferences / WebKit WebsiteData. Затем приложение запущено; installed app metadata подтверждает 1.0 (2), настоящий снимок телефона показывает рабочий первый экран с новой сводкой библиотеки.

Сохранение существующих файлов при обновлении доказано. Это не заменяет отдельный тест восстановления библиотеки из пользовательского экспортного бэкапа.

Резервная копия данных, signed build 1 для отката, xcresult, оригинальные device logs и снимок физического телефона остаются на личном Mac. В публичных документах нет hardware IDs, профилей подписи, секретов и личных книг.
