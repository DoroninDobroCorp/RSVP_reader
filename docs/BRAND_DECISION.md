# Brand collision screen and provisional decision

Screen date: 2026-08-11 (America/Santiago)

Decision: use **HummingRead** as the provisional release brand and keep **Pico**
as the hummingbird mascot. This result is **provisional pending owner/legal
confirmation**. It is a practical collision screen, not trademark clearance,
legal advice, a domain reservation, or permission to publish.

## Result at a glance

| Candidate | What the screen found | Decision |
| --- | --- | --- |
| HummingRead | No exact active reading, productivity, or software product was found in the searched app stores, extension store, web, GitHub, npm, or indexed trademark results. The exact `.com` and `.app` returned no RDAP record at the time of the check. | Provisional release brand, subject to owner/legal confirmation and a fresh pre-filing check. |
| PicoRead | Historic contactless-reader hardware/software use and an exact U.S. registration that was later cancelled. The exact name is too close to a technology product even though the mascot name Pico is not the same product mark. | Reject as product name; retain Pico only as mascot. |
| PaceFlow | A live Google Play running coach, another running-plan service, and an active engineering-management SaaS use the exact name. `paceflow.com` and `paceflow.app` have active RDAP records. | Reject as a supposedly cleared product name and remove it from current packaged/user-facing surfaces. |

## Store and software-name evidence

Searches used exact spelling plus spaced/confusing variants (`Humming Read`,
`Humming Reader`, `Pico Read`, and `Pace Flow`) where the service supported it.
Store search can vary by country and indexing, so a negative result is only a
screening signal.

- Apple App Store: Apple's public Search API returned no exact `HummingRead`
  title in the 2026-08-11 result set. The API returned related fuzzy results,
  but none used the exact candidate. Query:
  <https://itunes.apple.com/search?term=HummingRead&entity=software&limit=50>.
- Google Play: the English/US app search page explicitly returned “No results
  for HummingRead” on 2026-08-11:
  <https://play.google.com/store/search?q=HummingRead&c=apps&hl=en_US>.
- Chrome Web Store: the exact search returned no exact `HummingRead` product
  card in the server-rendered result on 2026-08-11:
  <https://chromewebstore.google.com/search/HummingRead?hl=en-US>.
- GitHub: the public repository API returned `total_count: 0` for exact-name
  repository search on 2026-08-11:
  <https://api.github.com/search/repositories?q=HummingRead+in:name&per_page=20>.
- npm: the exact package endpoint returned HTTP 404 on 2026-08-11:
  <https://registry.npmjs.org/hummingread>.
- Ordinary web searches for `"HummingRead"`, `"Humming Read" app`, and
  `"HummingRead" software` found no exact active software/product collision.
  This does not cover unindexed, private, newly filed, or regional uses.

The rejected candidates have affirmative conflicts:

- `PaceFlow` is a live Android product, **Paceflow: AI Running Coach**:
  <https://play.google.com/store/apps/details?id=com.paceflow.app>.
- `Paceflow` is also an active engineering-management software service:
  <https://www.paceflow.io/>. A separate active running-plan product uses the
  same term at <https://www.paceflow.co/>.
- `PicoRead` was an exact contactless-reader chipset/product name. The U.S.
  application serial `79031630`, registration `3385685`, is recorded as
  cancelled after the international registration was cancelled. Official case
  status entry: <https://tsdr.uspto.gov/#caseNumber=79031630&caseSearchType=US_APPLICATION&caseType=DEFAULT&searchType=statusSearch>.

## Trademark-database screen

Exact-word searches were attempted against the public USPTO TSDR/search entry,
EUIPO eSearch, and WIPO Global Brand Database, with ordinary web-index searches
used as a cross-check where the dynamic result interface did not expose a stable
shareable result URL. No exact `HUMMINGREAD` record was found in the accessible
results on 2026-08-11. `PICOREAD` produced the exact historic/cancelled U.S.
record described above. This screen is not exhaustive by owner, phonetic match,
translation, design mark, common-law use, class, or territory.

- USPTO trademark search: <https://tmsearch.uspto.gov/>
- USPTO status/document retrieval: <https://tsdr.uspto.gov/>
- EUIPO eSearch: <https://euipo.europa.eu/eSearch/>
- WIPO Global Brand Database: <https://branddb.wipo.int/>

Before filing or commercial launch, counsel or the owner must repeat a proper
clearance search for exact, phonetic, visual, and related-goods conflicts in the
intended software classes and launch territories.

## Social-handle screen

Exact indexed searches for `@hummingread` and direct profile-path checks across
X, Instagram, and TikTok did not surface an established exact product identity
on 2026-08-11. Social platforms can hide private/dormant accounts and can return
generic pages for absent handles, so the handles are **not claimed available**
and were not registered. Owner action is required to confirm and reserve chosen
handles after approving the provisional name.

## Why other known names are not used

- `StillGlyph`: distinctive, but abstract and less emotionally approachable.
- `RSVP Reader`: generic, crowded, and used by direct competitors.
- `RSVPanda`: active scheduling product and occupied domain.
- `StillWing`: active flight-anxiety application.
- `WordFox`, `BlinkFox`, and `WordWing`: existing products or developer identities.

## Release wording and gates

Use `HummingRead` for the product, `Pico` for the character, and descriptive
metadata such as “RSVP speed reader”, “speed reading”, “read faster”, and “focus
reader”. Do not imply affiliation with another company's product or mark.

Owner-only gates before public store submission:

1. Approve the HummingRead name and the proposed identifiers.
2. Obtain appropriate legal/trademark review for launch territories.
3. Re-run store, domain, social, and trademark checks immediately before filing.
4. Register domains/handles only through an explicitly authorized owner action.
