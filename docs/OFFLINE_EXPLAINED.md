# 🔌 Как работает оффлайн режим

## 📦 Двухуровневая система хранения

### 1️⃣ Service Worker - кэширование приложения

**Service Worker** - это JavaScript скрипт, который работает в фоновом режиме между браузером и сервером.

#### Как это работает:

```
Первый визит:
Браузер → Сервер → Загружает файлы → Service Worker сохраняет в Cache API

Последующие визиты:
Браузер → Service Worker → Проверяет кэш → Возвращает из кэша (БЕЗ интернета!)
```

#### Что кэшируется:
- `index.html` - главная страница
- `style.css` - все стили
- `app.js` - вся логика приложения
- `epub-parser.js` - парсер EPUB
- `manifest.json` - метаданные PWA

#### Файл: `service-worker.js`
```javascript
// При установке - сохраняем все файлы
self.addEventListener('install', (event) => {
  cache.addAll(['/index.html', '/style.css', '/app.js', ...]);
});

// При запросе - сначала проверяем кэш
self.addEventListener('fetch', (event) => {
  // Сначала ищем в кэше
  // Если нет - идём в сеть
  // Если сеть недоступна - отдаём из кэша
});
```

### 2️⃣ localStorage - хранение ваших данных

**localStorage** - это хранилище в браузере для сохранения данных пользователя.

#### Что хранится:
- **Текст** (`rsvp_text`) - весь введённый/загруженный текст
- **Закладка** (`rsvp_bookmark`) - позиция чтения (индекс слова)
- **Настройки** (`rsvp_settings`) - все параметры в JSON формате

#### Код сохранения:
```javascript
// Сохранение текста
localStorage.setItem('rsvp_text', textContent);

// Сохранение закладки
localStorage.setItem('rsvp_bookmark', currentIndex);

// Сохранение настроек
localStorage.setItem('rsvp_settings', JSON.stringify(settings));
```

#### Загрузка при старте:
```javascript
// Приложение автоматически загружает при запуске:
this.textInput.value = localStorage.getItem('rsvp_text') || '';
this.currentIndex = localStorage.getItem('rsvp_bookmark') || 0;
this.settings = JSON.parse(localStorage.getItem('rsvp_settings'));
```

## 🌐 Progressive Web App (PWA)

### Что это даёт:

1. **Установка на устройство**
   - Добавляется на главный экран как обычное приложение
   - Работает в полноэкранном режиме
   - Имеет свою иконку

2. **Работа без интернета**
   - После первой загрузки не требует подключения
   - Все функции доступны оффлайн
   - Данные сохраняются локально

3. **Файл манифеста** (`manifest.json`)
   ```json
   {
     "name": "RSVP Speed Reader",
     "display": "standalone",
     "start_url": "/",
     "icons": [...]
   }
   ```

## 🔄 Как это работает на практике

### Сценарий 1: Первое использование
1. Открываете `http://localhost:8081`
2. Service Worker регистрируется
3. Все файлы кэшируются в браузере
4. Вставляете текст → сохраняется в localStorage
5. **Готово!** Теперь можно работать оффлайн

### Сценарий 2: Работа оффлайн
1. Отключаете Wi-Fi / мобильный интернет
2. Открываете приложение (из закладок или с главного экрана)
3. Service Worker отдаёт файлы из кэша
4. localStorage загружает ваш текст и настройки
5. **Всё работает как обычно!**

### Сценарий 3: На телефоне
1. Открываете в Chrome/Safari
2. Нажимаете "Добавить на главный экран"
3. Приложение устанавливается как PWA
4. Загружаете EPUB или вставляете текст
5. Даже в режиме полёта можете читать!

## 📚 EPUB поддержка

### Как работает парсинг EPUB:

#### EPUB = ZIP архив с HTML файлами
```
book.epub
├── META-INF/
│   └── container.xml    (указывает на content.opf)
├── OEBPS/
│   ├── content.opf      (манифест книги)
│   ├── chapter1.xhtml   (текст главы 1)
│   ├── chapter2.xhtml   (текст главы 2)
│   └── ...
```

#### Процесс извлечения текста:

1. **Загрузка JSZip** (библиотека для работы с ZIP)
   ```javascript
   // Динамически подгружается только при загрузке EPUB
   script.src = 'https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js';
   ```

2. **Разархивирование EPUB**
   ```javascript
   const zip = new JSZip();
   const contents = await zip.loadAsync(epubFile);
   ```

3. **Поиск content.opf** (файл с порядком глав)
   ```javascript
   // Читаем META-INF/container.xml
   // Находим путь к content.opf
   ```

4. **Извлечение порядка чтения**
   ```javascript
   // Парсим XML
   // Получаем список глав в правильном порядке
   <spine>
     <itemref idref="chapter1"/>
     <itemref idref="chapter2"/>
   </spine>
   ```

5. **Извлечение текста из HTML**
   ```javascript
   // Для каждой главы:
   const html = await zip.file(chapterPath).async('string');
   // Удаляем теги, оставляем только текст
   const text = extractTextFromHTML(html);
   ```

6. **Объединение и вывод**
   ```javascript
   // Склеиваем все главы
   const fullText = chapters.join('\n\n');
   // Показываем в textarea
   ```

### Преимущества этого подхода:

✅ **Без внешних зависимостей** - JSZip загружается только при необходимости
✅ **Работает оффлайн** - после первой загрузки EPUB текст сохраняется в localStorage
✅ **Простота** - конвертация в plain text, без сложного форматирования
✅ **Универсальность** - работает с любыми EPUB файлами
✅ **Мобильность** - полностью работает на телефоне

### Ограничения:

⚠️ Теряется форматирование (жирный, курсив)
⚠️ Изображения игнорируются
⚠️ Сноски могут быть не в правильном порядке

Но для RSVP чтения это не критично - важен только текст!
