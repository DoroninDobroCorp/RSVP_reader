# 📚 Тестирование EPUB поддержки

## 🧪 Как протестировать загрузку EPUB

### Где взять тестовые EPUB файлы:

#### 1. **Project Gutenberg** (бесплатные книги)
- URL: https://www.gutenberg.org
- Огромная библиотека классической литературы
- Все книги в public domain
- Примеры:
  - "War and Peace" - https://www.gutenberg.org/ebooks/2600
  - "Crime and Punishment" - https://www.gutenberg.org/ebooks/2554
  - Выберите книгу → "Download" → выберите формат EPUB

#### 2. **Standard Ebooks** (качественные форматированные книги)
- URL: https://standardebooks.org
- Хорошо отформатированные классические произведения
- Бесплатные и без DRM

#### 3. **Feedbooks** (Public Domain раздел)
- URL: https://www.feedbooks.com/publicdomain
- Классические книги в различных форматах

#### 4. **Archive.org**
- URL: https://archive.org
- Огромная коллекция книг, многие доступны в EPUB

### Простой тест - создать свой EPUB:

#### Используйте Calibre (бесплатный инструмент):
1. Скачайте Calibre: https://calibre-ebook.com/download
2. Создайте TXT файл с текстом
3. Calibre → "Add books" → выберите TXT
4. Нажмите "Convert books" → выберите EPUB
5. Готово! Теперь можете загрузить в приложение

## 🐛 Возможные проблемы и решения:

### Проблема: "Не удалось найти файл content.opf"
**Причина:** Повреждённый или нестандартный EPUB
**Решение:** Попробуйте другой EPUB файл или используйте Calibre для конвертации

### Проблема: Текст извлёкся, но в неправильном порядке
**Причина:** EPUB без правильной структуры spine
**Решение:** Парсер попытается использовать manifest, но порядок может быть неверным

### Проблема: Много мусорного текста
**Причина:** EPUB содержит много метаданных или сносок
**Решение:** Можно вручную отредактировать текст после загрузки

### Проблема: JSZip не загружается
**Причина:** Не отдался локальный файл `vendor/jszip.min.js` или он не попал в кеш service worker
**Решение:** Проверьте, что файл существует, доступен по HTTP и указан в `service-worker.js`

```

4. Дождитесь сообщения "EPUB успешно загружен!"
5. Проверьте, что текст появился в textarea
6. Нажмите "Начать чтение"

```

```
1. Загрузите EPUB (онлайн)
2. Начните чтение
3. Откройте DevTools (F12)
4. Network tab → выберите "Offline"
5. Обновите страницу
6. Приложение должно загрузиться из кэша
7. Текст должен быть сохранён
8. RSVP должен работать нормально
```

```
1. Откройте на телефоне через браузер

4. Закройте браузер
5. Откройте через иконку на главном экране
6. Включите режим полёта
```
