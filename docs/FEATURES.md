# Возможности RSVP Reader

## Чтение

- RSVP: одно слово в центре, фокусная буква, настраиваемый размер шрифта.
- Обычный режим: прокручиваемый текст, подсветка текущего слова, переход по клику.
- Поиск по тексту с переходом между найденными словами.
- Двойной клик/двойной тап: обычный режим ↔ RSVP.
- Пробел в обычном режиме запускает RSVP, пробел в RSVP ставит паузу/продолжает.

## Скорость и паузы

- WPM от 100 до 1000.
- Отдельные множители пауз для запятой, точки и `; : ! ? …`.
- Автоматический расчёт оставшегося времени и общего времени чтения.

## Форматы

- Вставка текста вручную.
- `.txt`.
- `.epub` через локальный `vendor/jszip.min.js`, без внешнего CDN.
- `.fb2`/`.xml` FictionBook.
- `.docx` через локальный `vendor/jszip.min.js`.
- `.html`/`.htm`.
- `.md`/`.markdown`.
- `.rtf` с базовым извлечением текста.

## Библиотека

- Несколько книг в IndexedDB.
- Прогресс чтения отдельно для каждой книги.
- Дата последнего чтения.
- Переименование и удаление книг.
- Поиск по библиотеке.
- Импорт и экспорт библиотеки в JSON.

## Закладки

- Именованные закладки внутри книги.
- Короткий текстовый фрагмент рядом с закладкой.
- Быстрый переход из модального списка или из карточки книги.
- Закладки сохраняются вместе с книгой и переживают перезагрузку страницы.

## Оффлайн и PWA

- Service worker кеширует app shell и локальный JSZip.
- IndexedDB хранит книги, тексты, прогресс и закладки.
- `localStorage` используется для настроек и совместимости со старой версией.
- Web App Manifest позволяет установить приложение на устройство.

## Приватность

- Все тексты и книги остаются в браузере.
- Нет серверной части, аналитики, cookies и отправки данных наружу.

## Технический стек

- Vanilla JavaScript.
- IndexedDB, Cache API, Service Worker API.
- Playwright-тесты для RSVP, EPUB, offline, mobile double-tap, библиотеки и закладок.
