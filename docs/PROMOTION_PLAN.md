# HummingRead: спокойный запуск бесплатного open-source приложения

Дата: 24 октября 2026. Модель: все функции чтения бесплатны, код под MIT, добровольная поддержка. Платёжного аккаунта пока нет.

## Для кого и зачем

Для людей, у которых накопились EPUB, FB2, документы и длинные тексты. Главное обещание: «Ваши книги. Ваш темп». Не обещать рост понимания, лечения СДВГ, гарантированного ускорения или медицинских эффектов. Отличие — RSVP вместе с обычным текстом, контекстом на паузе, локальной библиотекой, закладками и возможностью переделать код под себя.

Не продавать открытый код как эксклюзивную технологию. Продавать здесь нечего: ценность — аккуратно собранная и поддерживаемая основа, удобство установки и доверие.

## Что подготовлено для магазина

Три набора названий, подзаголовков, описаний, промотекстов и ключевых слов: release/app-store/*.json. Команда npm run store:prepare выгружает поля по файлам. Ключевые слова подобраны по реальным форматам и действиям, без чужих брендов. Это гипотеза релевантности, а не исследование частотности или обещание позиций в поиске.

Первый скриншот — реальные книги/импорт, второй — режим RSVP с понятным управлением, третий — контекст на паузе. Затем сохранённая библиотека и поиск/закладки. Для демонстраций использовать собственные, синтетические или проверенные public-domain тексты.

## Как запускать без рекламного бюджета

1. Пройти реальный TestFlight и исправить ошибки, обнаруженные пользователями.
2. Записать короткий честный ролик: импорт своего EPUB → обычный текст → RSVP → пауза → возврат к месту.
3. Автор сам размещает текст в подходящих сообществах чтения, open source и независимых разработчиков, соблюдая их правила. Ничего автоматически не рассылать.
4. В README и профиле проекта дать сайт, код, поддержку и позже — реальную донатную ссылку.
5. Собирать конкретные замечания через email/GitHub. Не покупать отзывы и не просить только положительные оценки.
6. После появления данных смотреть доступные в App Store Connect просмотры страницы/установки и отдельно реальные добровольные взносы. Не добавлять трекинг SDK ради первого запуска.

## Добровольная поддержка

На сайте сейчас рабочие действия: попробовать, открыть код, прочитать MIT, написать автору. Пустой платёжной кнопки нет. Когда владелец зарегистрирует удобный сервис, добавить его HTTPS-ссылку в product.config.json → website.donationUrl и пересобрать. Сервис нужно выбрать по реальной доступности выплат владельцу; не считать иностранные выплаты доступными без проверки.

Пример будущего текста:
«HummingRead остаётся бесплатным. Если он вам полезен и хочется поддержать развитие, можно оставить добровольный взнос. Это не открывает скрытые функции и не создаёт подписку.»

Окупаемость не гарантируется. При чистом среднем взносе $3 нужно около 33 поддержек, чтобы покрыть $99 в год; при $5 — 20. Это сумма после комиссий и налогов, без расходов времени и других сервисов.
