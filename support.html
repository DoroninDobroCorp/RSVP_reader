HummingRead 1.0 · tester support

Support

Books and reading progress stay on your device. Before reporting a problem, export a backup from Settings if the app is still accessible.

Include in a report

  • device and iOS/iPadOS version;
  • file format and approximate size;
  • the exact steps that produced the problem;
  • whether it repeats after force-quit and relaunch.

Do not attach a book unless you own the rights and it is necessary to reproduce the issue.

This public page provides recovery guidance without a login, but it is not a no-login contact channel. A real support email or equivalent route is still an owner-supplied release blocker.

Testers may optionally use GitHub Issues for technical reports; GitHub normally requires an account. Open technical issue on GitHub

HummingRead 1.0 · поддержка тестеров

Поддержка

Книги и прогресс остаются на устройстве. Если приложение доступно, перед обращением экспортируйте резервную копию в Настройках.

Что указать

  • модель устройства и версию iOS/iPadOS;
  • формат и примерный размер файла;
  • точную последовательность действий;
  • повторяется ли проблема после принудительного закрытия.

Не прикладывайте книгу, если у вас нет прав на её передачу или файл не нужен для воспроизведения ошибки.

На этой публичной странице без входа собраны инструкции по восстановлению, но она не является каналом связи без аккаунта. Настоящий email поддержки или равноценный маршрут должен предоставить владелец — это блокер релиза.

Тестеры могут по желанию отправить технический отчёт через GitHub Issues; для этого обычно нужен аккаунт GitHub. Открыть технический issue в GitHub

HummingRead 1.0 · soporte para probadores

Soporte

Los libros y el progreso de lectura permanecen en tu dispositivo. Antes de informar sobre un problema, exporta una copia de seguridad desde Ajustes si la aplicación aún es accesible.

Incluir en un informe

  • dispositivo y versión de iOS/iPadOS;
  • formato de archivo y tamaño aproximado;
  • los pasos exactos que produjeron el problema;
  • si se repite tras forzar el cierre y reiniciar.

No adjuntes un libro a menos que poseas los derechos y sea necesario para reproducir el problema.

Esta página pública ofrece orientación de recuperación sin inicio de sesión, pero no es un canal de contacto sin cuenta. Un correo de soporte real o una ruta equivalente sigue siendo un bloqueador de lanzamiento del propietario.

Los probadores pueden usar opcionalmente GitHub Issues para informes técnicos; GitHub normalmente requiere una cuenta. Abrir problema técnico en GitHub
