# 📚 Улучшения EPUB парсера

## 🐛 Проблема

Первая версия парсера извлекала **все подряд** из EPUB:
- ❌ Обложки (cover pages)
- ❌ Титульные страницы
- ❌ Страницы с копирайтом
- ❌ Оглавление (TOC)
- ❌ SVG изображения
- ❌ Ссылки на CSS файлы
- ❌ Плохое форматирование текста (все в кучу)

### Пример "до":
```
<link rel="stylesheet" href="style.css" type="text/css"/>
<svg xmlns="http://www.w3.org/2000/svg">...</svg>
Орсон Скотт Кард Игра Эндера Джефри, который заставил меня...
```

Всё склеивалось в одну кашу без разделения глав! 😱

---

## ✅ Решение

### 1. **Пропуск служебных файлов**
```javascript
shouldSkipFile(fileName) {
    const skipPatterns = [
        'cover', 'coverpage', 'titlepage', 'title_page',
        'copyright', 'toc', 'nav', 'frontmatter'
    ];
    return skipPatterns.some(pattern => fileName.includes(pattern));
}
```

**Что делает:**
- Проверяет имя файла
- Если содержит "cover", "title", "toc" и т.д. → **пропускает**
- Обрабатываются только главы с реальным контентом

### 2. **Удаление мусорных элементов**
```javascript
// Удаляем всё ненужное
temp.querySelectorAll('script, style, svg, img, image, link, meta').forEach(el => el.remove());

// Удаляем навигацию и сноски
temp.querySelectorAll('nav, [role="doc-endnotes"], .footnotes').forEach(el => el.remove());
```

**Что удаляется:**
- `<script>` - JavaScript
- `<style>` и `<link>` - CSS
- `<svg>`, `<img>`, `<image>` - картинки
- `<meta>` - метаданные
- Навигация и блоки сносок

### 3. **Умная фильтрация коротких страниц**
```javascript
// Если меньше 30 слов - вероятно титульная страница
if (bodyText.trim().split(/\s+/).length < 30) {
    return ''; // Пропускаем
}
```

**Логика:**
- Обложки обычно содержат только название и автора (< 30 слов)
- Реальные главы длиннее → оставляем
- Это ловит страницы, которые не отфильтровались по имени

### 4. **Извлечение названий глав**
```javascript
extractChapterTitle(element) {
    const headings = element.querySelectorAll('h1, h2, .title, .title1, .chapter-title');
    if (headings.length > 0) {
        const title = headings[0].textContent.trim();
        if (title.length < 100) {
            return title;
        }
    }
    return null;
}
```

**Что делает:**
- Ищет заголовки (`<h1>`, `<h2>`, или класс `.title`)
- Проверяет длину (< 100 символов)
- Возвращает название главы

### 5. **Структурированная обработка абзацев**
```javascript
// Находим все параграфы
const elements = temp.querySelectorAll('p, div.p, div.p1, h1, h2, h3, h4, h5, h6');

elements.forEach(el => {
    const text = el.textContent.trim();
    if (text && !text.match(/^(cover|title|copyright|contents)/i)) {
        paragraphs.push(text);
    }
});

// Склеиваем с двойными переносами
chapterText = paragraphs.join('\n\n');
```

**Результат:**
- Каждый абзац отдельно
- Между абзацами двойной перенос строки
- Читается как нормальный текст!

### 6. **Разделение глав**
```javascript
// Главы разделяются чёткой линией
return textParts.join('\n\n---\n\n');
```

**Формат:**
```
Глава 1. Название

Текст первого абзаца...

Текст второго абзаца...

---

Глава 2. Название

Текст...
```

### 7. **Очистка лишних пробелов**
```javascript
chapterText = chapterText
    .replace(/\n{3,}/g, '\n\n')  // Максимум 2 переноса
    .replace(/[ \t]+/g, ' ')     // Множественные пробелы → один
    .trim();
```

## 🚀 Как использовать

1. **Обновите страницу** (Ctrl+R или Cmd+R)
   - Service Worker загрузит новую версию (v3)

2. **Загрузите EPUB**
   - Результат будет намного чище!

3. **Если не обновляется:**
   ```javascript
   // В консоли браузера (F12):
   navigator.serviceWorker.getRegistrations().then(registrations => {
       registrations.forEach(r => r.unregister());
   });
   // Затем обновите страницу
   ```

## 📝 Технические детали

### Алгоритм обработки:
```
1. Загрузить EPUB (ZIP архив)
2. Найти content.opf (манифест книги)
3. Получить список глав в правильном порядке
4. Для каждой главы:
   ├─ Проверить имя файла → пропустить служебные
   ├─ Загрузить HTML
   ├─ Удалить мусорные элементы
   ├─ Проверить количество слов → пропустить короткие
   ├─ Извлечь название главы
   ├─ Извлечь параграфы
   ├─ Отформатировать с переносами
   └─ Добавить в результат
5. Склеить главы с разделителем "---"
6. Вернуть готовый текст
```

### Что НЕ обрабатывается:
- ⚠️ Изображения (игнорируются)
- ⚠️ Форматирование (жирный/курсив теряется)
- ⚠️ Таблицы (превращаются в текст)
- ⚠️ Сноски внутри текста (остаются как ссылки "note 1")

Но для RSVP чтения это не критично - **главное чистый текст!**
